# CivicSense

**Report. Track. Resolve.**

An integrated civic issue reporting platform connecting citizens, municipal departments, and field officers.

---

## 🌟 Features & Milestones Completed

- **Citizen Portal**: Issue submission with photo evidence, department selection, and live GPS location capture.
- **Complaint Tracking**: Real-time status progress timeline (`NEW` → `ASSIGNED` → `IN_PROGRESS` → `RESOLVED`).
- **Officer Portal**: Department assigned queue, progress notes, and verified resolution with completion photo upload.
- **Admin Command Center**: System overview metrics, department clearance rates, officer roster, and analytical reports.
- **Notification System**: Instant bell popovers and notifications for citizens and officers.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
